# ThinkEconomics blog format

Every post needs a clear `slug`, `title`, `summary`, and a horizontal cover image. Write the body in short Markdown sections using `##` headings, then cite or link the data used in any published version.

Use this sequence:

1. State the question and why it matters.
2. Explain the core concept in plain language.
3. Show evidence, limits, and trade-offs.
4. Add a chart, graph, or interactive model where it helps readers test the idea.
5. End with the next question, not a forced conclusion.

For images in the current content system, insert `image:UNSPLASH_IMAGE_ID`. For interactive models, insert a supported block such as `interactive:supply` or `interactive:growth` on its own line.
